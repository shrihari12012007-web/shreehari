# Shree Hari S B — Interactive 3D Developer Portfolio

An interactive, physics-driven 3D developer portfolio and driving simulation engineered with Three.js, Cannon.js rigid-body dynamics, and procedural audio synthesis. Featuring dynamic day/night environmental illumination, full 360-degree orbital camera rotation, interactive obstacle physics, telemetry-responsive vehicle dynamics with engine audio, and automated multi-channel contact dispatch integrating mobile SMS and direct email alerts.
